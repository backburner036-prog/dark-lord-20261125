The dark lord has left the gate unbarred — not mercy, arithmetic. His dragon retired on a pension of sheep, his lieutenant unionised, the skeletons filed for overtime, and the cursed amulet was pawned for a mattress with actual springs. Let the hero have his legend; the dark lord has a kettle, a blanket, and a map with no X on it. The throne is free — he checked. It squeaks.

```bash
python3 main.py
```

This writes the 100-word monologue to `/output/entry.txt`.
